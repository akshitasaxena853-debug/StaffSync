# StaffSync — Modern Human Resource Management Solution

StaffSync is a full-stack MERN (MongoDB, Express, React, Node.js) web application designed to help organizations manage employees and common HR operations efficiently through a single interface.

## 🚀 Features
- **Dashboard:** System status and HR overview statistics.
- **Employee Management:** View employee records pulled directly from MongoDB Atlas, search records dynamically, and add new employees via a structured form.
- **Modern UI:** Clean, responsive interface built with React and Vite.

## 🛠️ Technology Stack
- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express.js, Mongoose
- **Database:** MongoDB Atlas (Cloud Database)
